# Performance Operacional AC Camargo

Painel HTML estático para GitHub Pages.

## Publicação

Envie os arquivos `index.html`, `README.md` e `.nojekyll` para a raiz do repositório e ative o GitHub Pages em Settings > Pages > Deploy from a branch > main > /root.

## Atualizações nesta versão

- Correção dos registros sem veículo para `Carro (Utilitário Leve)` / `Carro`.
- Inclusão do botão `Exportar CSV`, respeitando os filtros dinâmicos aplicados no painel.
